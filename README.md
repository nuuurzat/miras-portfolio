# Портфолио сайты

Минимализмді, қазіргі тренд палитрасындағы (крем + лайм акцент, қою режим қолдауымен) бір беттік портфолио. Ешқандай фреймворк қажет емес — таза HTML/CSS/JS.

## 🎛️ Админ-панель (ағымдағы басқару)

**Іске қосу:** компьютер үстеліндегі **«Портфолио-Админ»** файлын қосарлап басыңыз (немесе `python3 admin.py`).

- **Админ:** http://127.0.0.1:8138/admin — пароль: **miras1234** (кірген соң өзгертіңіз!)
- Мүмкіндіктер: мәтінді өзгерту (3 тіл), видео жүктеу/өшіру/реттеу, GitHub-қа бір батырмамен жариялау
- **Аналитика:** GitHub Pages трафигі (кірулер, бірегей келушілер) + видео ойнау санауышы
- Туннель басқаруы («Аналитика» бетінде) — телефоннан уақытша кіру сілтемесі
- Барлық өзгерістер `admin/admin_data.json`-нан жасалады және `js/content.js` автоматты генерацияланады (қолмен өзгертпеу керек)

## Файлдар

```
portfolio/
├── index.html        # бет құрылымы (бөлімдер)
├── css/style.css     # стильдер (палитра: :root және [data-theme="dark"])
├── js/content.js     # ⭐ БАРЛЫҚ КОНТЕНТ ОСЫНДА — өз деректеріңізді жазыңыз
├── js/main.js        # шығару логикасы, анимациялар (өзгерту қажет емес)
└── img/              # кейс видеолары (portfolio/img/)
```

## Контентті жаңарту

1. `js/content.js` — **3 тіл** (kk / ru / en): `languages` объектісінде әр тілдің өз `meta` (аты, рөлі, сипаттама), `ui` (интерфейс мәтіндері), `cases`, `services`, `stats` бөлімдері бар. Байланыс пен компаниялар тізімі (`contacts`, `companies`) барлық тілге ортақ.
2. Кейс **видеолары**: `portfolio/img/` қапшығына файл салып, кейстің `media` тізіміне жазыңыз:
   ```js
   media: [{ type: "video", src: "папка/файл.mp4", poster: "posters/папка/файл.mp4.png" }]
   ```
   `poster` — постер суреті (қажет емес, болмаса видеоның алғашқы кадры көрсетіледі). Басқанда лайтбокста ойналады. Видео жоқ болса — күту белгісі көрсетіледі.
3. Компаниялар: `companies` тізімінде әр элемент `{ name: "Атауы", href: "https://www.instagram.com/хэндл/" }` — `href` бос болса, аты сілтемесіз шығады.

## Тілдер мен шрифттер

- Тіл ауыстырғыш — жақтау жоғарыда: ҚАЗ / РУС / ENG. Таңдау `localStorage`-та сақталады.
- Шрифттер Google Fonts арқылы жүктеледі: **Golos Text** (тақырыптар) + **Inter** (мәтін) — екеуі де қазақ әріптерін (Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І) толық қолдайды.

## Видеоларды қалай қосуға болады

1. Ноутбукте `проект/кейс Мирас/` папкасына видеоларды салыңыз (ол Finder-да ашық тұр).
2. Маған айтыңыз — өзім `portfolio/img/` қапшығына көшіріп, `content.js`-те кейстерге қосамын.

## Жергілікті көру

```bash
cd portfolio
python3 -m http.server 8080
# → http://localhost:8080
```

(немесе `index.html` файлын браузерде тікелей ашуға да болады)

## Жариялау

- **GitHub Pages:** репозиторийге жүктеп, Settings → Pages → `main` / `root` таңдаңыз.
- **Netlify / Vercel:** папканы drag-and-drop немесе репозиторийден қосу — басқа конфигурация қажет емес.

## Ескертулер

- Түс режимі (light/dark) `localStorage`-та сақталады; қараңғы режимге `style.css` ішіндегі `[data-theme="dark"]` блок жауапты.
- Кейс видеолары браузерде ойнайтын форматта болуы керек: MP4 (H.264) немесінше WebM. MOV-тарды салсанда — ойнамауы мүмкін, MP4-ке айналдырамыз.
